# CombatLR Website

Source files for the CombatLR public website.

The site will use the established CombatLR visual identity: black, white and tactical green, with the CombatLR logo as the primary brand element.

## Structure

- `assets/` — shared images, logos, icons and other static assets
- `css/` — site stylesheets
- `js/` — site scripts
- `downloads/` — downloadable application and firmware releases
- `documentation/` — user guides and technical documentation
- `pages/` — additional website pages

## Binary downloads

Every published binary must include its file name, version, file size and MD5 checksum. Generate checksums from the final release files; do not enter them manually. A `checksums.txt` file should accompany each release batch.

MD5 is retained for compatibility and accidental-corruption checks. It is not a cryptographic authenticity guarantee.
