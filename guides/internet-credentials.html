GETTING STARTED / 03

Internet credentials.

Before a player unit can join your local network, it needs the Wi-Fi details. CombatLR includes a small web-based provisioning tool in the ESP32 firmware, so you can configure the network and FTP login without connecting a cable or editing a configuration file.

You'll need

A powered CombatLR ESP32 player unit, the name (SSID) and password for the Wi-Fi network you want it to use, and an FTP username and password for file transfers. Have the details ready before starting.

1. Start provisioning mode

With the player unit switched off, press and hold the Trigger and Right switches, then power on the unit. Keep both switches held while it starts.

The firmware checks the switch combination after its initial two-second power-up period. Trigger + Right selects Provisioning mode. The display shows the provisioning indicator and the access point address.

Use the correct switch combination

Trigger + Right starts network provisioning. Trigger + Reload starts the separate FTP transfer mode used later when transferring game files.

2. Connect to the CombatLR access point

On a phone, tablet or computer, open the Wi-Fi network list and connect to the access point created by the player unit:

Network name (SSID)CombatLR
Wi-Fi passwordcombatlr
Configuration addresshttp://192.168.4.1

Your device may report that this Wi-Fi network has no internet access. That is expected: it is a direct connection to the ESP32, not your normal internet connection. Choose to remain connected.

3. Open the configuration page

While connected to the CombatLR access point, open a web browser and enter http://192.168.4.1 in the address bar. The CombatLR Network Setup page is served directly by the player unit.

The page displays the Wi-Fi network entries and FTP fields. Any currently saved values are shown so that you can review or change them.

4. Enter your Wi-Fi networks

The form provides eight network slots. Enter the SSID and password for each network the player unit may need to join. You can configure one network or several; blank SSID entries are ignored.

  • Network 1 is the first network in the list.
  • Add further networks if the unit needs to work in more than one location, or if you use different networks for setup and play.
  • Enter the Wi-Fi password in the matching password field.
  • Leave unused network slots blank.

At least one SSID must be supplied before the form can be saved. The firmware stores the configured networks and tries them when it starts its normal Wi-Fi connection process. It remembers the network that connected successfully and tries that one first on a subsequent start.

5. Set the FTP credentials

In the FTP section of the same page, enter the username and password that the file-transfer client will use when connecting to this player unit.

These are the credentials for the ESP32's FTP service. They are separate from the Wi-Fi password used to join your network. Use the same FTP username and password when configuring the device in the CombatLR Mobile transfer workflow.

6. Save the configuration

Select Save Configuration. The ESP32 checks that at least one Wi-Fi network has been entered and writes the Wi-Fi and FTP settings to /system.json in its LittleFS storage.

If the save succeeds, the page confirms that the configuration has been saved. The unit then leaves provisioning mode and continues through its normal startup sequence. The temporary CombatLR access point and configuration page stop running.

Keep a record of the FTP login

The FTP username and password you enter here are needed later when transferring files. Store them somewhere you can retrieve them; do not include real passwords in screenshots, shared documentation or support posts.

7. Use the unit on your network

Once the unit has restarted, it attempts to connect to the configured Wi-Fi networks. The unit and the Android device running CombatLR Mobile need to be on the same local network for discovery and file transfer.

When you are ready to transfer the map and game plan, start the unit in FTP mode by holding Trigger and Reload while powering it on. The FTP service uses the username and password configured above. The firmware's FTP service uses port 21 and TLS; use a compatible secure FTP client.

Remember

The provisioning access point is only for configuring the player unit. Once setup is complete, use your normal local Wi-Fi network for device discovery and file transfer. The match itself does not depend on a venue-installed Wi-Fi network or continuous communication between player units.
