01 / THE SYSTEM

More than
laser tag.

CombatLR — Combat Laser Royale — brings together embedded hardware, GPS mapping and a companion mobile app to create flexible outdoor, combat royale laser-tag experiences anywhere, without site networking infrastructure.

With a high res image of your site, and a few GPS coordinates, any area (with good GPS coverage) can be transformed into a battle royal game

Virtual Health, ammo and weapons pickups can be placed around your site map with the mobile app, zones can be placed, sized and given a lifetime. Multiple weapons types (currently 8!) are available and up to 16 supported. New weapons can be created simply by adding some images, sounds and editing a config file

CombatLR uses GPS time to synchronise the placement and movement of zones across all players. No communication is required between player units once the game starts

Each player carries an ESP32-based game unit. The unit manages infrared firing and hit detection, audio, game state and its display. The mobile app prepares game plans, maps and player configurations, then coordinates the game.

02 / UNDER THE HOOD

One system.
Three parts.

Using an overhead image of the site, and 4 known GPS locations around it. The MapBuilder app (Windows) is used to create a playfield. The files created by this are then used by the mobile app (Android tablet recommended) to create a game plan. The game plan file is wirelessly exported to the player units, and GPS time is used by the player unit to synchronise zone placement and movement across all players. GPS is also used by the player units to access pickups scattered around the zones by the game plan designer

04 / THE HARDWARE

Open by design.
Field ready.

At the heart of each player unit is a compact, ESP32-powered controller designed to be straightforward to build, configure and maintain.

  • Easy to solderDesigned with accessible through-hole connections and clearly arranged interfaces.
  • Open-source designThe hardware and firmware are developed as an open project.
  • ESP32 poweredWireless connectivity and enough capability to run the complete player unit.
  • Compact footprint110 × 48 mm PCB.
  • On-board audioAudio samples are stored locally on the ESP32, ready for playback during a game.
  • Easy to maintainConfigure and update the unit without dismantling it.
  • OTA firmware updatesInstall firmware updates wirelessly over the air.
  • FTP gameplay updatesTransfer game data and configuration files to the unit over Wi-Fi.
