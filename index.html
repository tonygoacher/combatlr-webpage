CombatLR brings Battle Royale gameplay to the real world. GPS time is used to sychronise game zones and transitons across all players. Players see zones move to a new position on their player units at the same time.

GPS positioning makes sure they stay in the safe zone, and allows them to pick up virtual weapons and ammo bonuses shown on their unit map.

GPS-driven safe zones, scattered pickups and multiple weapons turn suitable outdoor locations into evolving game worlds — without installing equipment around the venue. Everything is driven by GPS.

PUBLIC RELEASE

It's launched!

After months of building, testing, debugging and rather a lot of 3D printing, CombatLR is now out in the open.

CombatLR is an open-source, GPS-based laser tag system that brings Battle Royale-style gameplay to suitable outdoor locations. Moving safe zones, virtual pickups and multiple weapons turn a real-world map into an evolving battlefield — without the need to install fixed equipment around the venue.

The firmware, mobile app, tools and hardware design are being shared so other people can explore the project, build their own equipment and experiment with the idea. The first release is a starting point, not the end of the story: field testing and development are continuing, and I'll add updates here as things progress.

01 / THE GAME

A changing
battlefield.

CombatLR takes the ideas that make Battle Royale games compelling and brings them outside: a play area that changes over time, resources worth searching for, and players who must decide when to fight and when to move.

Game designers create a GPS-calibrated game plan, define the zones and their timings, and scatter virtual pickups around the playfield.

Game plans are uploaded to the player units once and GPS time synchronises game progress across all players.

It is designed for suitable outdoor locations with GPS coverage. There is no need to install base stations, sensors, site Wi-Fi or a central game server around the venue.

Everything you need.

Prepare the map and game plan before play. Transfer the plan to the player units, start the game, and let GPS positioning and GPS time keep the experience in sync.

03PLAY

Self-contained units

Each ESP32 unit handles GPS, game logic, infrared firing and hit detection, audio and the player's display.

✓

No infrastructure at the venue. The game plan is loaded before play. GPS time synchronises zone behaviour across player units, so they do not need continuous communication with one another once the game has started. GPS coverage is required; site-installed networking or tracking equipment is not.

04 / THE HARDWARE

Designed for
DIY.

Each player carries a self-contained ESP32-based game unit. The hardware and firmware are part of the open project, so others can inspect, reproduce and adapt the design.

  • ESP32-poweredRuns the game logic and manages the player experience.
  • GPS positioning and timeProvides location and shared timing for synchronised zones.
  • Infrared combatHandles firing and hit detection between player units.
  • Data driven weaponsAdd new weapons by editing a file and adding new graphics and sound files.
  • Audio and display ESP32 stores sounds as .WAV files (mono, 16kHz). Change them if you wish using FTP mode. Low cost 2" LCD display is readily available.
  • Wireless setup Load game plans and update firmware without a wired connection.
  • Open designExplore the source and hardware resources to build your own.
  • Manageable Components Easily sourced components. Some surface mound devices are used to keep the size down, but nothing smaller than 0805. Easy for any competent hobbyist.
